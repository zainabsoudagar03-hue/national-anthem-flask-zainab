# National Anthem Project — Git & GitHub Practice Workshop

A simple Flask web application that displays the Indian National Anthem.  
This repository was created as part of a hands-on Git & GitHub workshop covering:

- Creating and cloning repositories
- Push & Pull collaboration
- Branching
- Merging
- Resolving merge conflicts
- Recovering work with reflog

---

## Project Structure

```
anthem-workshop/
├── app.py                  # Flask application
├── anthem.txt              # First line of the anthem
├── templates/
│   └── index.html          # Webpage showing the anthem
└── README.md
```

---

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/zainabsoudagar03-hue/national-anthem-flask-zainab/tree/main
cd anthem-workshop
```

2. Install Flask (if needed):
```bash
pip install flask
```

3. Run the app:
```bash
python3 app.py
```

4. Open in browser: (http://localhost:5000)

---

## Workshop Learning Outcomes

- A branch is just a pointer to a commit
- Always `git pull` before starting work
- Conflicts are normal and must be resolved by humans
- Committed work can usually be recovered with `git reflog`
